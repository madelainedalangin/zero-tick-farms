# 0 Tick Crops (Minecraft 26.1.2)
 
A Fabric mod that restores 0-tick plant growth, the behaviour Mojang removed in Minecraft 1.16 update. Forcing a scheduled block tick on a crop/plant (for example with a
0-tick sticky piston) triggers its growth, enabling 0-tick farms.
 
This is a community port to **Minecraft 26.1.2** (Fabric, Mojang mappings) of
the original mod by **tildejustin**.
