# 0 Tick Crops (Minecraft 26.1.2)
 
A Fabric mod that restores 0-tick plant growth, the behaviour Mojang removed in Minecraft 1.16 update. Forcing a scheduled block tick on a crop/plant (for example with a
0-tick sticky piston) triggers its growth, enabling 0-tick farms.
 
This is a community port to **Minecraft 26.1.2** (Fabric, Mojang mappings) of
the original mod by **tildejustin**.

## Requirements
 
- **Minecraft** 26.1.2
- **Fabric Loader** 0.19.2 or newer
- **Fabric API** (the build for Minecraft 26.1.2)

**Note:** this mod needs **Fabric Loader 0.19.2 or later**.
If your Fabric Loader is older than 0.19.2, please update it or the mod won't load. A newer loader (0.19.3, etc.) is always fine. The requirement is a 
minimum, not an exact match.
 
## Install
 
1. Install **Fabric Loader** (0.19.2 or newer) for Minecraft 26.1.2, using the
   official Fabric installer from fabricmc.net.
2. Download **Fabric API** for 26.1.2.
3. Put both the Fabric API `.jar` and this mod's `.jar` in your `mods/` folder.
4. Launch Minecraft using the Fabric profile.
